# Trámites DT Express

Sitio web oficial de Trámites DT Express – Servicios vehiculares en Panamá.

## Servicios
- Traspasos Vehiculares
- Retiro de Stickers/Placas
- Revisado Vehicular
- Seguro de Autos
- Cambio de Municipio
- Retiro de Circulación
- Liberación de Hipotecas
- Duplicado de RUV
- Inscripción de Vehículo

## Características
✅ Diseño moderno y responsive  
✅ Contador de trámites (+4200)  
✅ Botón flotante de WhatsApp  
✅ Solicitud directa por servicio  
✅ Totalmente funcional sin backend
